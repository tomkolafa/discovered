# Design drop

Put the Discovered brand assets here and they get wired into the app:

- `logo.svg` (preferred) or `logo.png` — app header + landing page
- `icon.svg` / `icon-512.png` — PWA home-screen icon (square, safe margin ~10%)
- Landing page design: Figma link, PDF, or screenshots (`landing-*.png`)
- `colours.md` or the palette hex values, if they differ from the current tokens
